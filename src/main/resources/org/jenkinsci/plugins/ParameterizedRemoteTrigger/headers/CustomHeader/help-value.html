The value of the HTTP header to send with requests to the remote Jenkins server.

Token Macro Support: This field supports Jenkins token macros. You can use build variables and environment variables such as:

  • ${BUILD_NUMBER}
  • ${JOB_NAME}
  • ${GIT_COMMIT}

Security: If the "Mark as Secret" checkbox is enabled, this value will be:

  • Encrypted at rest in Jenkins configuration files using hudson.util.Secret
  • Masked in console output and logs (Jenkins automatically masks Secret values)

Use the secret option for sensitive values like API keys, tokens, or other credentials.

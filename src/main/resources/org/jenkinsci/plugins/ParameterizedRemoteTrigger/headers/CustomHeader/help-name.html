The name of the HTTP header to send with requests to the remote Jenkins server.

Examples:

  • X-API-Key - API authentication key
  • X-Tenant-ID - Multi-tenant identifier
  • X-Client-Name - Identifying client application

Token Macro Support: This field supports Jenkins token macros. You can use build variables and environment variables such as:

  • X-Build-${BUILD_NUMBER}
  • X-Job-${JOB_NAME}

Note: Certain headers like Authorization, Content-Type, Content-Length, and the CSRF crumb header are protected and cannot be overridden.
